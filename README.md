# DynamicDave.Umbraco.ContentHealth

Finds broken internal links in Umbraco content: a Link health dashboard in the Content section and a Link health view on every document.

Umbraco 17 and 18 backoffice package (`DynamicDave.Umbraco.ContentHealth`). See [the package README](src/DynamicDave.Umbraco.ContentHealth/README.md).
