# DynamicDave.Umbraco.ContentHealth

Finds broken internal links in Umbraco content: a Link health dashboard in the Content section (counts, filters, CSV export) and a Link health view on every document (its broken links and the pages that link to it).

The backoffice UI is localized in English, Dutch, German, French and Danish (`src/DynamicDave.Umbraco.ContentHealth/Client/src/localization`).

Umbraco 17 and 18 backoffice package (`DynamicDave.Umbraco.ContentHealth`). See [the package README](src/DynamicDave.Umbraco.ContentHealth/README.md) for what it does, configuration and limitations.
